# Welcome to AppSec Atlas

AppSec Atlas is a comprehensive, community-driven security knowledge base covering 45 guides across 9 security domains. Whether you're a developer wanting to write more secure code, a security engineer deepening your expertise, or a complete beginner — there is a path here for you.

## How to Use This Atlas

### Option 1: Follow a Learning Path
We have designed role-based learning paths that guide you through the most relevant guides in the right order. See [Learning Paths](learning-paths.md).

### Option 2: Browse by Domain
Use the [main README](../../README.md) table of contents to find guides in your area of interest.

### Option 3: Use the Search (Website)
Visit [appsecatlas.com](https://appsecatlas.com) and use the Algolia-powered search to find specific topics instantly.

### Option 4: Start with a Checklist
If you need quick-reference material, our [checklists](../../checklists/) are designed for immediate use.

## Understanding Guide Levels

| Level | Meaning |
|-------|---------|
| **Beginner** | No prior security knowledge required. Basic programming helps. |
| **Intermediate** | Some security or programming background assumed. |
| **Advanced** | Requires solid security fundamentals and technical depth. |
