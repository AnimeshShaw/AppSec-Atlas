# 07 - References and Further Reading

To fully master SOC 2 and compliance engineering, consult the authoritative sources below.

## 🏛 Official Frameworks
- **[AICPA SOC 2 Guidelines](https://us.aicpa.org/interestareas/frc/assuranceadvisoryservices/sorhome)**
  The definitive source for the Trust Services Criteria (TSC) directly from the American Institute of CPAs.
- **[Cloud Security Alliance (CSA) Cloud Controls Matrix (CCM)](https://cloudsecurityalliance.org/research/working-groups/cloud-controls-matrix)**
  A cybersecurity control framework for cloud computing. Excellent for mapping SOC 2 controls to technical implementations.

## ☁️ Cloud Provider Compliance Resources
- **[AWS SOC Compliance](https://aws.amazon.com/compliance/soc-faqs/)**
  AWS Artifact allows you to download AWS's own SOC 2 report to inherit their physical security controls.
- **[Google Cloud SOC Reports](https://cloud.google.com/security/compliance/soc-2)**
  Similar to AWS, download GCP's reports for your Vendor Management evidence.
- **[Azure SOC 2](https://learn.microsoft.com/en-us/azure/compliance/offerings/offering-soc-2)**

## 📚 Security Tooling and Automation
- **[Vanta](https://www.vanta.com/)** - Continuous compliance automation platform.
- **[Drata](https://drata.com/)** - Compliance and risk management OS.
- **[Secureframe](https://secureframe.com/)** - Automated SOC 2 and ISO 27001 compliance.
- **[Terraform AWS Provider](https://registry.terraform.io/providers/hashicorp/aws/latest/docs)** - Infrastructure as Code documentation for automating compliant environments.

## 📖 Recommended Reading
- *Engineering Compliance: The Developer's Guide to SOC 2* (Articles and blog series often published by engineering teams going through their first audit, e.g., on Medium or engineering blogs of companies like Segment, Stripe, or HashiCorp).
