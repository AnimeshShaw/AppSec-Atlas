# 07 - References & Further Reading

## Official NIST Resources
*   **[NIST Cybersecurity Framework 2.0 Official Publication](https://www.nist.gov/cyberframework)**: The primary source and foundational text for the framework.
*   **[NIST CSF 2.0 Reference Tool](https://cprt.nist.gov/)**: An interactive tool for exploring the Core, Profiles, and Tiers.
*   **[NIST SP 800-53 Rev. 5](https://csrc.nist.gov/publications/detail/sp/800-53/rev-5/final)**: Security and Privacy Controls for Information Systems and Organizations. The CSF directly crosswalks to these detailed controls.

## Associated Frameworks & Tools
*   **[CISA Cyber Essentials](https://www.cisa.gov/cyber-essentials)**: A guide for leaders of small businesses as well as leaders of small and local government agencies to develop an actionable understanding of where to start implementing organizational cybersecurity practices.
*   **[Open Policy Agent (OPA)](https://www.openpolicyagent.org/)**: The open-source, general-purpose policy engine used for compliance automation.
*   **[AWS Security Hub - NIST CSF Standard](https://docs.aws.amazon.com/securityhub/latest/userguide/nist-standard.html)**: AWS documentation on automated NIST CSF mapping.
*   **[Microsoft Defender for Cloud - Regulatory Compliance](https://learn.microsoft.com/en-us/azure/defender-for-cloud/regulatory-compliance-dashboard)**: Azure's approach to mapping infrastructure to the NIST CSF.
