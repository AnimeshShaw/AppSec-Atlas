# 07 - References and Further Reading

To dive deeper into the world of hardware security, explore the following industry standards, tools, and documentation:

## Tools and Frameworks
*   **ChipWhisperer:** The industry standard open-source toolchain for embedded security research, side-channel power analysis, and voltage glitching. 
    *   [ChipWhisperer Documentation](https://rtfm.newae.com/)
*   **OpenOCD (Open On-Chip Debugger):** Open-source software for debugging and programming embedded systems via JTAG and SWD.
    *   [OpenOCD User Guide](https://openocd.org/doc/html/index.html)
*   **Saleae Logic Analyzers:** Highly popular logic analyzers for hardware hacking and signal snooping.
    *   [Saleae Website](https://www.saleae.com/)

## Standards and Guidelines
*   **NIST SP 800-147 (BIOS Protection Guidelines):** Standards for secure boot and firmware protections.
    *   [NIST SP 800-147 PDF](https://csrc.nist.gov/publications/detail/sp/800-147/final)
*   **FIPS 140-3:** Security Requirements for Cryptographic Modules (covering tamper evidence and resistance).
    *   [FIPS 140-3 Standard](https://csrc.nist.gov/publications/detail/fips/140/3/final)
*   **Trusted Computing Group (TCG):** The consortium defining the TPM 2.0 specifications.
    *   [TCG Specifications](https://trustedcomputinggroup.org/)

## Books
*   *Hardware Hacker: Adventures in Making and Breaking Hardware* by Andrew "bunnie" Huang.
*   *The Hardware Hacker's Handbook* by Jasper van Woudenberg and Colin O'Flynn.
