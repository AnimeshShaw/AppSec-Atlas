# 07 - References and Resources

To further your knowledge in Web Application Security, refer to these industry-standard guidelines and interactive platforms.

## Official Documentation & Guidelines
- **OWASP Web Security Testing Guide (WSTG):** The premier cybersecurity testing resource for web application developers and security professionals.
  - [WSTG Repository](https://owasp.org/www-project-web-security-testing-guide/)
- **OWASP Top 10:** The top 10 most critical web application security risks.
  - [OWASP Top 10](https://owasp.org/www-project-top-ten/)
- **MDN Web Docs - Security Headers:** Comprehensive documentation on implementing HTTP security headers.
  - [MDN HTTP Headers](https://developer.mozilla.org/en-US/docs/Web/HTTP/Headers)

## Interactive Learning
- **PortSwigger Web Security Academy:** Free, interactive, and highly practical labs created by the makers of Burp Suite. Excellent for mastering modern web exploits.
  - [Web Security Academy](https://portswigger.net/web-security)
- **OWASP Juice Shop:** Probably the most modern and sophisticated insecure web application for hands-on practice.
  - [Juice Shop](https://owasp.org/www-project-juice-shop/)

## Tooling References
- **OWASP ZAP Documentation:** [ZAP Proxy](https://www.zaproxy.org/docs/)
- **Burp Suite Documentation:** [Burp Suite Support](https://portswigger.net/burp/documentation)
- **Nmap NSE Scripts for HTTP:** [NSE Documentation](https://nmap.org/nsedoc/scripts/)
