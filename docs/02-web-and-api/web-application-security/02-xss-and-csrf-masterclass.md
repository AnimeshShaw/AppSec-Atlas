# 02 - XSS and CSRF Masterclass

## Cross-Site Scripting (XSS)
XSS occurs when an application includes untrusted data in a web page without proper validation or escaping.

### Types of XSS
1. **Stored XSS:** The malicious script is permanently stored on the target servers (e.g., in a database via a comment field).
2. **Reflected XSS:** The injected script is reflected off the web server, such as in an error message or search result.
3. **DOM-based XSS:** The vulnerability exists in the client-side code rather than the server-side code.

### Vulnerable Code vs Secure Code

#### Python (Flask) Reflected XSS
**Vulnerable:**
```python
@app.route('/greet')
def greet():
    name = request.args.get('name', '')
    # Vulnerable: directly rendering user input
    return f"<h1>Hello, {name}</h1>"
```

**Secure:**
```python
from markupsafe import escape

@app.route('/greet')
def greet():
    name = request.args.get('name', '')
    # Secure: Context-aware HTML escaping
    return f"<h1>Hello, {escape(name)}</h1>"
```

### CSP Nonce Hardening
For inline scripts, a nonce (number used once) can be generated per request and included in the CSP header.
```html
<!-- Server generates nonce and injects it here -->
<script nonce="rAnd0mN0nc3">
  console.log("This script runs because the nonce matches the CSP header.");
</script>
```

## Cross-Site Request Forgery (CSRF)
CSRF forces an end user to execute unwanted actions on a web application in which they are currently authenticated.

### Anti-CSRF Tokens
A unique, unpredictable token generated by the server and validated on state-changing requests.

### SameSite Cookie Attributes
Modern browsers support the `SameSite` attribute for cookies to mitigate CSRF.
- `Strict`: Cookie is not sent on cross-site requests.
- `Lax`: Cookie is sent with top-level navigations (e.g., following a link).

#### Node.js (Express) CSRF Protection
**Secure Implementation:**
```javascript
const express = require('express');
const cookieParser = require('cookie-parser');
const csrf = require('csurf');

const app = express();
app.use(cookieParser());

// SameSite cookie configuration
const csrfProtection = csrf({ 
    cookie: { 
        httpOnly: true, 
        sameSite: 'strict' 
    } 
});

app.get('/form', csrfProtection, (req, res) => {
    // Pass the CSRF token to the view
    res.render('send', { csrfToken: req.csrfToken() });
});

app.post('/process', express.urlencoded({ extended: false }), csrfProtection, (req, res) => {
    res.send('Data is being processed');
});
```
