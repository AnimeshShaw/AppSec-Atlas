# 07 - References & Resources

To dive deeper into Mobile Application Security, refer to these industry-standard resources:

## OWASP Standards
- **[OWASP Mobile Application Security Verification Standard (MASVS)](https://github.com/OWASP/owasp-masvs)**
  The industry standard for mobile security requirements, establishing baseline security criteria for developers and testers.
- **[OWASP Mobile Application Security Testing Guide (MASTG)](https://github.com/OWASP/owasp-mastg)**
  The ultimate manual for mobile app security testing and reverse engineering, serving as the practical companion to the MASVS.

## Official Platform Security Guides
- **[Android Security Best Practices](https://developer.android.com/topic/security/best-practices)** - Official Google documentation.
- **[Apple Platform Security](https://support.apple.com/guide/security/welcome/web)** - Deep dive into iOS security architecture, Secure Enclave, and code signing.

## Tooling References
- **[MobSF (Mobile Security Framework)](https://github.com/MobSF/Mobile-Security-Framework-MobSF)**
- **[Frida Dynamic Instrumentation](https://frida.re/)**
- **[Objection by SensePost](https://github.com/sensepost/objection)**
