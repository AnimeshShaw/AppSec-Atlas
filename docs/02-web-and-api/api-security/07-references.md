# 07. References & Testing Tools

Authoritative references, testing frameworks, and tooling for API Security.

---

## 1. Official Standards & Benchmarks

- **[OWASP API Security Top 10 (2023)](https://owasp.org/www-project-api-security/)** — The official OWASP API security reference.
- **[OpenAPI Specification (v3.1.0)](https://spec.openapis.org/oas/v3.1.0)** — Standard specification format for REST APIs.
- **[NIST SP 800-204](https://csrc.nist.gov/publications/detail/sp/800-204/final)** — Security Strategies for Microservices Architecture.

---

## 2. API Security Testing & Audit Tools

- **[Nuclei API Vulnerability Templates](https://github.com/projectdiscovery/nuclei-templates)** — Fast automated vulnerability scanner for APIs.
- **[Postman API Security Scanner](https://www.postman.com/)** — Automated API contract testing and security header checks.
- **[Kiterunner](https://github.com/assetnote/kiterunner)** — Context-aware API endpoint discovery tool.
- **[GraphQLmap](https://github.com/swisskyrepo/GraphQLmap)** — Scripting engine to audit GraphQL targets.

---

## 3. Real-World CVE References

- **CVE-2022-22965 (Spring4Shell)**: Remote Code Execution via Data Binding / Mass Assignment in Spring Framework (API3).
- **CVE-2023-30845 (Apollo Server)**: Introspection and memory usage exhaustion (API4).
