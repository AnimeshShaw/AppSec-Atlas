# 07. References and Resources

To deepen your understanding of frontend security, refer to these authoritative resources and specifications.

## 📚 Official Documentation & Guidelines

- **MDN Web Docs: Web Security**
  Comprehensive guides on web security features, HTTP headers, and browser mechanisms.
  [https://developer.mozilla.org/en-US/docs/Web/Security](https://developer.mozilla.org/en-US/docs/Web/Security)

- **OWASP Client-Side Security Cheat Sheet**
  Best practices for securing client-side architecture and handling data in the browser.
  [https://cheatsheetseries.owasp.org/cheatsheets/HTML5_Security_Cheat_Sheet.html](https://cheatsheetseries.owasp.org/cheatsheets/HTML5_Security_Cheat_Sheet.html)

- **OWASP Cross Site Scripting Prevention Cheat Sheet**
  Detailed strategies for preventing XSS across different contexts.
  [https://cheatsheetseries.owasp.org/cheatsheets/Cross_Site_Scripting_Prevention_Cheat_Sheet.html](https://cheatsheetseries.owasp.org/cheatsheets/Cross_Site_Scripting_Prevention_Cheat_Sheet.html)

## 📜 Standards & Specifications

- **W3C Content Security Policy Level 3**
  The official specification for CSP v3, detailing strict policies, nonces, and hashes.
  [https://w3c.github.io/webappsec-csp/](https://w3c.github.io/webappsec-csp/)

- **W3C Trusted Types**
  The specification for preventing DOM-based Cross-Site Scripting vulnerabilities via Trusted Types.
  [https://w3c.github.io/trusted-types/dist/spec/](https://w3c.github.io/trusted-types/dist/spec/)

- **Subresource Integrity (SRI)**
  Documentation on how to ensure third-party resources haven't been tampered with.
  [https://developer.mozilla.org/en-US/docs/Web/Security/Subresource_Integrity](https://developer.mozilla.org/en-US/docs/Web/Security/Subresource_Integrity)

## 🛠️ Tools

- **DOMPurify**
  A DOM-only, super-fast, uber-tolerant XSS sanitizer for HTML, MathML and SVG.
  [https://github.com/cure53/DOMPurify](https://github.com/cure53/DOMPurify)

- **Retire.js**
  Scanner detecting the use of JavaScript libraries with known vulnerabilities.
  [https://retirejs.github.io/retire.js/](https://retirejs.github.io/retire.js/)
