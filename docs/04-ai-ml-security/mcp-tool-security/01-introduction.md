# 01 - Introduction to MCP & Tool-Use Security

## Theory and Architecture
The Model Context Protocol (MCP) is an open standard designed to facilitate secure, standardized communication between AI models (Clients) and external data sources or tools (Servers). It uses JSON-RPC over stdio or HTTP/SSE.


## Threat Landscape
When an AI model can autonomously invoke tools:
1.  **Confused Deputy Problem:** The LLM is tricked via Prompt Injection into using its tools maliciously.
2.  **Tool Poisoning / Malicious Servers:** A compromised or malicious MCP server provides dangerous tools or falsified data back to the LLM.
3.  **Data Exfiltration:** An attacker uses a legitimate tool (like `fetch_url`) to send sensitive context out of the environment.

## Root Causes
- **Implicit Trust:** Trusting the parameters generated by the LLM without validation.
- **Over-privileged Tools:** Tools that have broad access (e.g., `execute_shell_command` with root access).
- **Lack of User Consent:** Executing state-changing actions without Human-In-The-Loop (HITL) approval.
