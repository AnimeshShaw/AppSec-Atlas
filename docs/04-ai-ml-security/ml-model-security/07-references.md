# 07. References & Standards

Authoritative benchmarks, security standards, and open-source toolkits for Machine Learning Security.

---

## 1. Standards & Security Guidelines

- **[NIST AI 100-2 (Artificial Intelligence Risk Management Framework)](https://www.nist.gov/itl/ai-risk-management-framework)** — Official NIST guidelines for AI security and robustness testing.
- **[MITRE ATLAS™ Framework](https://atlas.mitre.org/)** — Threat matrix for artificial intelligence systems.
- **[RobustBench Benchmark](https://robustbench.github.io/)** — Standardized benchmark for adversarial robustness in deep learning.

---

## 2. Open-Source Toolkits

- **[Adversarial Robustness Toolbox (ART)](https://github.com/Trusted-AI/adversarial-robustness-toolbox)** — Python library for ML security evaluation (Linux Foundation).
- **[Microsoft Counterfit](https://github.com/Azure/counterfit)** — Command-line tool for assessing security of ML models.
- **[CleverHans](https://github.com/cleverhans-lab/cleverhans)** — Adversarial example library for PyTorch and TensorFlow.
