# 06. References & Tooling

Authoritative resources, security guidelines, and open-source tools for CI/CD Pipeline Security.

---

## 1. Standards & Security Guidelines

- **[SLSA Framework (v1.0 Specification)](https://slsa.dev/)** — Google & OpenSSF supply chain security framework.
- **[GitHub Actions Security Hardening Guide](https://docs.github.com/en/actions/security-guides/security-hardening-for-github-actions)** — Official security guidance for Actions.
- **[CISA Open Source Software Security Roadmap](https://www.cisa.gov/resources-tools/resources/open-source-software-security-roadmap)** — US CISA guidance for software supply chains.

---

## 2. CI/CD Security Tools

- **[TruffleHog](https://github.com/trufflesecurity/trufflehog)** — High-precision secret scanner for git commit histories and CI pipelines.
- **[StepSecurity Harden-Runner](https://github.com/step-security/harden-runner)** — Runtime network and file monitoring for GitHub Actions runners.
- **[Cosign / Sigstore](https://github.com/sigstore/cosign)** — Container signing and verification toolkit.
- **[Trivy](https://github.com/aquasecurity/trivy)** — Comprehensive vulnerability scanner for containers, filesystems, and IaC templates.
