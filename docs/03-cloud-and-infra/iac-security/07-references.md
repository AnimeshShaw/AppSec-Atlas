# 07 - References and Resources

To deepen your understanding of Infrastructure as Code (IaC) security, refer to the following industry standards, documentation, and tools.

## 📚 Standards and Benchmarks

- **CIS Foundations Benchmarks**: (Center for Internet Security) Consensus-based security configuration guides for AWS, Azure, and GCP.
  - [CIS AWS Foundations Benchmark](https://www.cisecurity.org/benchmark/amazon_web_services/)
  - [CIS Microsoft Azure Foundations Benchmark](https://www.cisecurity.org/benchmark/azure/)
  - [CIS Google Cloud Computing Platform Benchmark](https://www.cisecurity.org/benchmark/google_cloud_computing_platform/)

## 🛠️ Security Tools Documentation

- **Checkov (Prisma Cloud)**
  - Docs: [https://www.checkov.io/](https://www.checkov.io/)
  - GitHub: [https://github.com/bridgecrewio/checkov](https://github.com/bridgecrewio/checkov)
- **tfsec (Aqua Security)**
  - Docs: [https://aquasecurity.github.io/tfsec/](https://aquasecurity.github.io/tfsec/)
- **Terrascan (Tenable)**
  - Docs: [https://runterrascan.io/](https://runterrascan.io/)
- **Driftctl**
  - GitHub: [https://github.com/snyk/driftctl](https://github.com/snyk/driftctl)

## 📜 Policy as Code Frameworks

- **Open Policy Agent (OPA) / Rego**
  - Official Documentation: [https://www.openpolicyagent.org/docs/latest/](https://www.openpolicyagent.org/docs/latest/)
  - OPA Terraform Integration: [https://www.openpolicyagent.org/docs/latest/terraform/](https://www.openpolicyagent.org/docs/latest/terraform/)
- **HashiCorp Sentinel**
  - Sentinel Documentation: [https://docs.hashicorp.com/sentinel/](https://docs.hashicorp.com/sentinel/)

## 📖 Cloud Provider Security Best Practices

- **AWS Security Best Practices for CloudFormation**: [AWS Documentation](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/security-best-practices.html)
- **Azure Security Center and Bicep**: [Microsoft Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/bicep/security)
