# 07. References & Standards

Authoritative frameworks, guides, and tools for Penetration Testing.

---

## 1. Standards & Security Guidelines

- **[PTES (Penetration Testing Execution Standard)](http://www.pentest-standard.org/)** — Industry standard penetration testing framework.
- **[OWASP Web Security Testing Guide (WSTG v4.2)](https://owasp.org/www-project-web-security-testing-guide/)** — Comprehensive manual for web application security auditing.
- **[CVSS v4.0 Specification](https://www.first.org/cvss/v4.0/specification-document)** — FIRST CVSS v4.0 calculator and metric standards.

---

## 2. Open-Source Audit Tools

- **[Nuclei](https://github.com/projectdiscovery/nuclei)** — Fast and customizable vulnerability scanner.
- **[Subfinder](https://github.com/projectdiscovery/subfinder)** — Passive subdomain discovery tool.
- **[OWASP Amass](https://github.com/owasp-amass/amass)** — In-depth network mapping and attack surface discovery tool.
- **[Nmap](https://nmap.org/)** — Network exploration tool and security / port scanner.
