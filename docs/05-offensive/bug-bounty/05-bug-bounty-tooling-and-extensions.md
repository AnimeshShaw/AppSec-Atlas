# 05. Tooling & Burp Suite Extensions

Using specialized Burp Suite extensions automates repetitive authorization and parameter discovery tasks.

## 1. Key Burp Suite Extensions

- **Autorize**: Automatic authorization enforcement tester.
- **Param Miner**: Discovers hidden unlinked GET/POST parameters.
- **Logger++**: Advanced logging and regex search for HTTP traffic.
