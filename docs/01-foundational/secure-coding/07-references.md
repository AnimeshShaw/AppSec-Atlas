# Chapter 7: References & Resources

## Industry Standards & Frameworks
- **[OWASP Secure Coding Practices Quick Reference Guide](https://owasp.org/www-project-secure-coding-practices-quick-reference-guide/)**: A checklist to ensure your software is developed securely.
- **[SEI CERT Coding Standards](https://wiki.sei.cmu.edu/confluence/display/seccode/SEI+CERT+Coding+Standards)**: Detailed rules and recommendations for secure coding in C, C++, Java, and Perl.
- **[NIST SSDF (Secure Software Development Framework)](https://csrc.nist.gov/Projects/ssdf)**: A set of fundamental, sound, and secure software development practices based on established secure software development practice documents.

## Tooling & Documentation
- **[Semgrep Rules Repository](https://semgrep.dev/explore)**: Explore community-driven static analysis rules for various languages.
- **[Pydantic Documentation](https://docs.pydantic.dev/)**: Data validation and settings management using Python type annotations.
- **[Zod Documentation](https://zod.dev/)**: TypeScript-first schema declaration and validation library.
- **[DOMPurify](https://github.com/cure53/DOMPurify)**: A DOM-only, super-fast, uber-tolerant XSS sanitizer for HTML, MathML and SVG.
