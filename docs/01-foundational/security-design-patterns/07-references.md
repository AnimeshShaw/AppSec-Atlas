# 07 - References

## Standards and Frameworks
- **OWASP Security Design Principles:** Guidelines for architecting secure software. [OWASP Design Principles](https://owasp.org/www-project-developer-guide/draft/design/security_principles)
- **SEI CERT Secure Design:** Best practices from the Software Engineering Institute.
- **NIST SP 800-160:** Systems Security Engineering - Considerations for a Multidisciplinary Approach in the Engineering of Trustworthy Secure Systems. [NIST Publication](https://csrc.nist.gov/publications/detail/sp/800-160/vol-1/rev-1/final)

## Threat Modeling
- **STRIDE by Microsoft:** [Microsoft Threat Modeling](https://learn.microsoft.com/en-us/azure/security/develop/threat-modeling-tool)
- **OWASP Threat Dragon:** [Threat Dragon Project](https://owasp.org/www-project-threat-dragon/)

## Design Patterns Literature
- **Cloud Design Patterns:** [Azure Architecture Center](https://learn.microsoft.com/en-us/azure/architecture/patterns/)
- **Microservices Patterns by Chris Richardson:** Contains extensive details on patterns like Circuit Breaker, API Gateway, and Sidecar.
