# 07 - References and Resources

To dive deeper into cryptographic standards, best practices, and implementation guidelines, refer to the following authoritative resources.

## Standards and Guidelines
- **NIST SP 800-175B**: Guideline for Using Cryptographic Standards in the Federal Government: Cryptographic Mechanisms.
- **NIST Post-Quantum Cryptography Standardization**: Details on FIPS 203, 204, and 205.
- **OWASP Cryptographic Storage Cheat Sheet**: High-level best practices for storing sensitive data.
- **OWASP Password Storage Cheat Sheet**: Recommendations for KDFs and password lifecycle.

## Libraries and Documentation
- **Python**: [PyCryptodome Documentation](https://pycryptodome.readthedocs.io/) and [Cryptography.io](https://cryptography.io/en/latest/).
- **Node.js**: [Node.js Web Crypto API](https://nodejs.org/api/webcrypto.html) and [Node.js Crypto Module](https://nodejs.org/api/crypto.html).
- **Go**: [Go `crypto` Package](https://pkg.go.dev/crypto).

## Further Learning
- **Cryptopals Crypto Challenges**: A series of exercises that demonstrate how cryptographic systems fail and how to exploit them.
- **Serious Cryptography by Jean-Philippe Aumasson**: An excellent book covering modern cryptography concepts for practitioners.
