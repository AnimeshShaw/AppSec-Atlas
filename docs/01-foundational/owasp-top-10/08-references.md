# 08. References & Tooling

Authoritative references, benchmarks, and security tools for OWASP Top 10 auditing.

---

## 1. Official OWASP Resources & Cheat Sheets

- **[OWASP Top 10 Official Document](https://owasp.org/Top10/)**
- **[OWASP Cheat Sheet Series](https://cheatsheetseries.owasp.org/)** — Industry standard secure coding cheat sheets for developers.
- **[OWASP Web Security Testing Guide (WSTG)](https://owasp.org/www-project-web-security-testing-guide/)** — Comprehensive testing methodology for penetration testers.

---

## 2. Automated Vulnerability Scanners & Tools

- **[Semgrep](https://semgrep.dev/)** — Open-source static analysis engine for code review.
- **[OWASP ZAP (Zed Attack Proxy)](https://www.zaproxy.org/)** — Free, open-source DAST web vulnerability scanner.
- **[Bandit](https://github.com/PyCQA/bandit)** — Python security linter.
- **[ESLint Security Plugin](https://github.com/eslint-community/eslint-plugin-security)** — Node.js security linter.

---

## 3. Notable CVE References

- **CVE-2021-44228 (Log4Shell)**: Remote Code Execution via JNDI injection (A03 / A06).
- **CVE-2023-34362 (MOVEit Transfer)**: SQL Injection allowing unauthenticated data exfiltration (A03).
- **CVE-2024-21626 (runc Container Escape)**: File descriptor leak leading to container breakout (A01 / A05).
