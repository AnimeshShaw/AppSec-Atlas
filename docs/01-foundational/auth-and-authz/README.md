# Authentication & Authorization Masterclass

Welcome to the **Authentication & Authorization Masterclass**. This module covers the foundational principles and advanced security patterns for identity management, access control, and secure token handling.

## Overview
Identity is the new perimeter. Understanding how to securely verify user identity (Authentication) and enforce access rights (Authorization) is critical to modern application security. This masterclass dives into session management, modern protocols (OAuth2/OIDC), token security (JWT), and authorization models (RBAC, ABAC, ReBAC).

## Prerequisites
- Basic understanding of HTTP protocol (Requests, Responses, Headers, Cookies).
- Familiarity with web application architectures (client-server).
- Basic programming knowledge in Python, Node.js, or similar languages.

## Learning Objectives
1. Understand the core difference between Authentication (AuthN) and Authorization (AuthZ).
2. Learn the mechanics and security considerations of Session-based vs Token-based authentication.
3. Master modern authentication flows including OAuth 2.0, OIDC, and MFA/WebAuthn.
4. Exploit and secure JSON Web Tokens (JWT) against common vulnerabilities.
5. Implement robust authorization models (RBAC, ABAC) and Policy as Code (OPA).
6. Gain hands-on experience through practical labs and exploit scenarios.
